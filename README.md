# Form Builder

A dynamic web application that allows users to build a form in real time.

## How It Works
The app has two sections:

**Form Builder** — Select a field type (Text Input, Checkbox, or Radio Button),
enter a label, and click "Add Field".

**Form Preview** — Every added field is instantly displayed as a live form preview.

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in your browserw.
